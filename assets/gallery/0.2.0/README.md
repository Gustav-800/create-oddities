## CurseForge 上传

CurseForge 的项目画廊没有公开写入 API（Upload API 只支持项目文件）。需要手动操作：

1. 打开作者后台的 Create Oddities 项目
2. 进入 **Media**
3. **Add Image**，按上表顺序上传
4. 标题和说明可直接使用上表
5. 保存后刷新项目页确认
